# Библиотека: клиент для серверного API

Практическая работа 4. Приложение из практической работы 3 больше не хранит данные у себя: каталог, авторы, жанры, издательства, читатели и выдачи загружаются с сервера и изменяются запросами к нему.

## Запуск

1. Запустить учебный сервер (папка с `mock-server.js`):

   node mock-server.js --port 8080 --origin http://localhost:5555

2. Запустить клиент на закреплённом порту, чтобы совпадал разрешённый источник:

   flutter pub get
   flutter run -d chrome --web-port=5555

Адрес сервера и учётная запись задаются при запуске, в коде их нет:

   flutter run -d chrome --web-port=5555 --dart-define=API_BASE_URL=http://localhost:8080/api --dart-define=API_USER=admin --dart-define=API_PASSWORD=admin123

Если параметры не указаны, используются значения из примера выше.

## Проверка отдельных случаев

- Сервер остановлен: в списке появляется сообщение об ошибке и кнопка «Повторить».
- Адрес `http://localhost:5555/?__fail=500`: сервер отвечает ошибкой 500 на каждый запрос.
- Адрес `http://localhost:5555/?__delay=1500`: каждый ответ приходит с задержкой, виден индикатор загрузки.
- Книга с уже существующим ISBN: сообщение сервера выводится под полем ISBN (ответ 422).
- Выдача книги, у которой не осталось свободных экземпляров: сообщение о конфликте (ответ 409).
- Сервер запущен с чужим значением `--origin`: браузер блокирует запросы, в консоли видна ошибка CORS.

## Устройство слоя доступа к данным

- `lib/core/config.dart` — адрес сервера и учётная запись из `--dart-define`.
- `lib/core/api_client.dart` — настройка Dio: таймауты, вход, общая обработка ошибок, журнал запросов, повторы чтения.
- `lib/core/api_exceptions.dart` — собственные исключения предметной области; Dio за пределы репозиториев не выходит.
- `lib/repositories/api_*.dart` — репозитории по сущностям; поиск, фильтры, сортировка и страницы выполняет сервер.

## Тесты

   flutter test

Репозитории проверяются на подменённом адаптере Dio: разбор ответов, ошибки 422, 409, 500, недоступный сервер, повторы чтения, кэш справочников, отмена устаревших запросов, повторный вход.
